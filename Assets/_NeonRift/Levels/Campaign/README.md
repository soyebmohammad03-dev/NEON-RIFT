# Neon Rift campaign (Night Run → Harbor Rain)

- Entry scene: `Scenes/CampaignBootstrap.unity` (the standalone game stays at `Assets/_NeonRift/Scenes/Bootstrap.unity`).
- Data: `Data/` (campaign config, definition, car selections, Harbor Rain mission entry, intro settings).
- Tools: `Editor/CampaignBuilder.cs` (Neon Rift ▸ Campaign ▸ Build Campaign), `Editor/CampaignAndroidBuild.cs`
  (campaign APK), `Editor/CampaignPlaytest.cs` (Neon Rift ▸ Campaign ▸ Playtest: …). Tests: `Tests/`.
- Local-only (not in the public repository): the voice recordings `Generated/Audio/Campaign_VO_*` (macOS System
  Voices, personal use only) and the two Harbor Rain cars.

Full documentation: `Docs/CAMPAIGN.md`, `Docs/BUILDING.md`, `Docs/TESTING.md` at the repository root.
