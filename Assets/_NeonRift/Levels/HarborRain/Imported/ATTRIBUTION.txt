Harbor Rain imported third-party models. Originals are kept unchanged in Assets/ThirdParty/Sketchfab/Vehicles and
Assets/ThirdParty/Sketchfab/Ships. Copies here are extracted from those archives; large ship textures were downscaled to
2048 px (sips) to keep the project small. Nothing else was modified.

Provenance re-checked on 2026-10-18 against the Sketchfab API (api.sketchfab.com/v3/models/<uid>: licence, author,
description). The downloaded archives themselves contain no licence file.

Harbor Rain 2.2 (2026-10-17) - trucks, trailer, containers, forklifts
No new third-party files were downloaded or imported for 2.2. The port truck (cab-over 4x2 tractor + 40 ft skeletal
container trailer), the ISO container (castings, door gear, markings), the forklift (two-stage mast, carriage, forks,
overhead guard, LPG bottle) and the Euro pallet loads are original geometry generated in code
(Editor/HarborRainBuilder.Tractor.cs, .Trailer.cs, .Truck.cs, .Forklift.cs; prefabs in Generated/Truck). Container
owner codes (NRXU, KWBU, TLHU, SKRU, HBCU, VRGU) are fictional. Weathering / tread / marking textures are generated.
Candidates considered and NOT used:
  - MAN TGX 2010 V8 (DevPoly3D, sketchfab.com/3d-models/34ce748d9a4b4de7b035cfe5cb97f5d1, page says CC BY 4.0):
    rejected - a public comment alleges it was ripped from Euro Truck Simulator 2; provenance unresolved.
  - DAF XF 95 (Kabourek Roman @Krakatit, sketchfab.com/3d-models/daf-xf-95-1e61dfadf7114ad38076f1a6a871ccf1, CC BY 4.0,
    provenance judged reasonable): approved, but the file was never obtained (Sketchfab download needs the owner's
    login), so nothing from it is in the project.
  - Forklift (Ethian74, sketchfab.com/3d-models/d40cae50e04145dd997cdca415cd72ad, CC BY 4.0): not downloaded (login).
Poly Haven CC0 textures already listed above remain the only imported surface sources.
