## Two layers

1. **Supplied music tracks** (used by default): `Assets/ThirdParty/SoundAudio/`.
2. **A procedural adaptive score** (original, generated by `ScoreComposer`): the **fallback** when no track is assigned, and the source of the intro's procedural fallback theme.

## Procedural adaptive score (`ScoreComposer` + `ScoreMix`)

| | |
|---|---|
| Composer | `Scripts/Editor/Audio/ScoreComposer.cs`: one 8-bar theme in **A minor at about 96 bpm** (Am(add9) – Fmaj7 – Dm9 – Esus4 → E, two bars each), rendered as four stems of exactly the same length (882,048 samples, a whole number of 128-sample ADPCM blocks, so the loop never gains a gap). Tempo derived from that length: 95.995 bpm |
| Stems | **Bed** (detuned-saw pad + sub), **Pulse** (soft kick, sidechained eighth-note bass, hats), **Arp** (sixteenth plucks, dotted-eighth echo), **Drive** (four-on-the-floor, claps, rolling bass, alarm stab, tom fills); outros **success** (resolves to A major with a bell arpeggio) and **failure** (low A/Bb/E cluster sinking a semitone) |
| Mixing rules (pure) | `Scripts/Missions/ScoreMix.cs`: `ScoreLayer`, `Targets(security, tension)`, `Step`, `NextGridTime` |
| Runtime | `MissionAudio.StartScore`: all stems start on one scheduled DSP tick (`PlayScheduled`) so they stay sample-locked. Layers rise 0.8/s and fall 0.4/s; the drive stem slams in at 4/s. Security changes land on the **next half bar** (`SetScoreSecurity`), so the lockdown hits on the grid with the stinger. `EndScore` fades over 1.2 s and plays the outro on the next beat |

| Stem | Calm | Heist work (× tension) | Alert | Lockdown |
|---|---|---|---|---|
| Bed | 0.80 | 0.80 | 0.55 | 0.20 |
| Pulse | 0.45 | → 0.22 | 0.85 | 0.55 |
| Arp | 0 | → 0.80 | 0.35 → 0.85 | 0.25 × tension |
| Drive | 0 | 0 | 0 | 1.00 |

When `MissionAudioSet.musicTrack` is assigned (as it is now), the supplied track **replaces** the stems.

## Intro music fallback

If the trailer track is missing, `IntroBuilder` falls back to the game's own theme: `Intro_Bed` / `Intro_Groove` from `IntroAudioGenerator` (`Scripts/Editor/Audio/IntroAudioGenerator.cs`). The groove joins at the bed's position in the loop, so both stay on the same bar and chord.

## Music on/off

**M** / gamepad **Y** anywhere (`GameRoot`, `GameSettings.ToggleMusic`); also in Settings (master, music, effects and interface volumes plus a music on/off switch). See [29](29_AUDIO_SYSTEM.md).
