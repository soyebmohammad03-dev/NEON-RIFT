# NEON RIFT: NIGHT RUN — Technical Book

| File | What it is |
|---|---|
| **[`NEON_RIFT_COMPLETE_TECHNICAL_BOOK.pdf`](NEON_RIFT_COMPLETE_TECHNICAL_BOOK.pdf)** | **The primary, human-readable book.** One PDF with a cover, a clickable Contents and List of Figures, Find It Fast, the Master Index, all 48 chapters in 12 parts, the developer quick reference, the viva Q&A cards, the glossary, the full script index and the documentation audit. | `01_…md` – `48_…md` | The chapters as searchable, editable Markdown source. The PDF is compiled from these files. |
| `DOCUMENTATION_AUDIT.md` | How the book was checked against the repository, including notes on the PDF edition. |

Use the PDF for reading, demonstrations and viva preparation. Use the Markdown files for searching (`grep`) and for editing. If a chapter changes, regenerate the PDF from the Markdown so the two stay identical.
