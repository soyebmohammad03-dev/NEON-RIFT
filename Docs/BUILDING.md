# Building

Everything below is an editor menu in **Neon Rift ▸ …** (Unity 6000.6.4f1). Most of the world is generated by code;
the generated output is committed, so you only rebuild after changing a builder.

## Generated content

| Content | Menu | Notes |
|---|---|---|
| Night Run city and mission | `Night Run ▸ Build Night Run (district + mission)` | about 40 s including the reflection-probe bake |
| Opening cinematic | `Intro ▸ Build Intro (open Night Run scene)` | Timeline, shots, cues |
| Car Select garage | `Car Select ▸ Build Garage` | |
| Vehicles | `Vehicles ▸ Build All Vehicle Prefabs`, `Vehicles ▸ Update Car Select Stats From Physics` | stats come from the physics bench |
| Harbor Rain level | `Harbor Rain ▸ Build Scene` | regenerates the whole scene, meshes, materials, audio and (on macOS) the radio voice lines |
| Harbor Rain police car / Level 2 cars | `Harbor Rain ▸ Build Police Car`, `Harbor Rain ▸ Build Level 2 Cars` | the Level 2 cars need the local-only source models |
| Campaign data and bootstrap | `Campaign ▸ Build Campaign (assets, voice, bootstrap scene)` | selections, configs, voice (macOS), portal, teaser frames, `CampaignBootstrap.unity`, scene list |

Run `Validate Project` afterwards: it checks configs, catalogs and the scene list.

## Scene list

`ProjectSettings/EditorBuildSettings.asset` keeps the original order with `Bootstrap` first, then the two campaign
scenes appended:

```
0 Scenes/Bootstrap  1 Scenes/Frontend  2 Scenes/CarSelect  3 Scenes/Dev/TestTrack  4 Scenes/NightRun
5 Levels/Campaign/Scenes/CampaignBootstrap  6 Levels/HarborRain/Scenes/HarborRain
```

Each APK script passes its own explicit list, so the two builds never pick up each other's scenes.

## Android APKs

| APK | Menu | Script | Scenes (index 0 = entry) | Application id | Output |
|---|---|---|---|---|---|
| Standalone Night Run | `Build ▸ Android APK (Release / Development)` | `Scripts/Editor/Validation/AndroidBuild.cs` | Bootstrap, Frontend, CarSelect, Dev/TestTrack, NightRun | `com.soyebmohammad.neonrift` | `Builds/Android/NEON_RIFT_NIGHT_RUN[_release].apk` |
| **Complete campaign** | `Campaign ▸ Build Campaign APK (Release / Development)` | `Levels/Campaign/Editor/CampaignAndroidBuild.cs` | CampaignBootstrap, Frontend, CarSelect, NightRun, HarborRain | `com.soyebmohammad.neonrift.campaign` | `Builds/Android/NEON_RIFT_COMPLETE_CAMPAIGN.apk` |

Both use the project's Android settings (`AndroidBuild.Configure()`: ARM64, IL2CPP, APK rather than AAB, landscape),
minimum API 26, Vulkan with an OpenGL ES 3 fallback. **Signing:** no custom keystore is configured, so Unity signs
with its debug keystore; that is fine for side-loading but not for a store.

The campaign script:
- sets the campaign application id only for the build and restores the original afterwards;
- writes `Builds/Android/NEON_RIFT_COMPLETE_CAMPAIGN_manifest.txt` (Unity version, target, id, scenes, size,
  result) and the full log to `Logs/Campaign/AndroidBuild_Campaign.txt`;
- restores, byte for byte, the files Unity rewrites as a side effect of an Android build
  (`Mobile_RPAsset.asset`, `UniversalRenderPipelineGlobalSettings.asset`, `UnityConnectSettings.asset`);
- moves an existing output aside before building and never touches the standalone APKs.

Unity leaves the editor on the Android target after a build; switch back with *File ▸ Build Profiles* if you work
on desktop. A release build takes about 5–9 minutes on an Apple-silicon Mac once the Android import cache exists
(the first switch to Android reimports the project and takes much longer).

## Distribution

**The campaign APK is not published and should not be shared publicly in its current form.** It is suitable only for
the owner's personal, non-commercial use:

| Content in the APK | Problem for public distribution |
|---|---|
| Ferrari 296 Speciale A, Ferrari F40 Liberty Walk | provenance unverified or contradicted (one source page says the model and texture come from the game CSR2) |
| Harbor Rain work boat | no author or licence |
| Voice recordings (66 lines) | macOS System Voices: Apple's licence forbids publishing or redistributing them |
| Terzo Millennio (CC BY-NC), AMG GT3 model (CC BY-NC-SA, not in the catalog) | non-commercial only (compatible with a free, attributed, non-commercial release) |
| Passenger-car pack, two music tracks | supplied by the owner with no recorded source or licence |

A public build would need: the two Harbor Rain cars removed (the project already runs without them), the voice
lines left as subtitles or re-recorded with a voice whose licence allows distribution, the work boat removed, and the
sources and licences of the passenger-car pack and the music recorded. GitHub release assets may be up to 2 GiB
each, so the size itself is not the obstacle; the licensing is.
